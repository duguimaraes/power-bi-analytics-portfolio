# 📊 Travel Advance & Expense Workflow Dashboard
🇧🇷 Versão em português: [README.pt-br.md](./README.pt-br.md)

## 🎯 Objective

Support the administrative team by providing clear visibility into travel-related requests, including advances and expense reports, enabling better tracking of workflow stages, current responsible users, and pending activities throughout the process.

---

## 🧰 Tools & Technologies

* Power BI (Data Visualization & Dashboarding)
* DAX (Measures & KPIs)
* SQL (Data Extraction & Workflow Consolidation)
* Power Query (Data Cleaning & Modeling)

---

## 📈 Key Metrics

* Total number of requests
* Requests by type (Advance vs Expense Report)
* Requests by current workflow stage
* Requests by current responsible user
* Requests by business unit
* Monthly historical volume of advances and expense reports
* Open vs completed request tracking

## 💡 Insights

* Provides strong support for administrative and management presentations, offering clear visibility into the status of travel-related requests.
* Enables quick identification of which workflow stage each request is currently in and who is responsible for the activity.
* Helps monitor bottlenecks in the process by highlighting requests concentrated in specific stages or with specific users.
* Supports tracking of request volume by type, business unit, and activity, improving operational control.
* Allows better follow-up of open requests and improves accountability across the workflow.

---

## 📂 Data & Queries

This project includes SQL queries organized in `queries.sql`, responsible for:

* Extracting the latest version of each travel request
* Consolidating advances and expense reports into a unified dataset
* Tracking workflow status (open and completed)
* Mapping the current workflow stage and responsible user
* Structuring administrative, financial, and travel-related fields for analysis

---

## 📊 Data Modeling

Data was structured and transformed in Power BI using Power Query and DAX, enabling workflow analysis by request type, activity, responsible user, and business unit.

---

## ⚠️ Notes

* All data used in this project is **anonymized and slightly adjusted** to preserve confidentiality.
* Labels and values were modified while maintaining the original analytical logic and business context.

---

## 🚀 Business Impact

This dashboard enables:

* Better administrative control over travel-related requests
* Clear visibility into the current stage and responsible user of each request
* Faster identification of process bottlenecks and pending activities
* Improved follow-up of open requests and workflow accountability
* Data-driven decisions to improve efficiency in travel expense processes
